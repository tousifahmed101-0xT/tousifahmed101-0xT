## Hi, I'm Tousif Ahmed

Cybersecurity undergraduate focused on web application security, vulnerability assessment,
and hands-on security research. This profile documents learning, experiments, and practice
work conducted in controlled, ethical environments.

---

## Areas of Focus

**Web Application Penetration Testing**
Security assessments of web applications, identifying and exploiting vulnerabilities
across authentication, authorization, and input handling layers.

**OWASP Top 10 Analysis**
Practical hands-on analysis of OWASP Top 10 categories including injection, broken
access control, and security misconfigurations.

**Vulnerability Identification and Reporting**
Identification, impact analysis, and professional documentation of security findings
with clear remediation guidance.

**Security Automation Fundamentals**
Scripting and ethical tool usage for security workflows including scanning,
enumeration, and report generation.
