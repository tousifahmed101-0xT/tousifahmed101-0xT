## About

Cybersecurity undergraduate with a focused interest in web application security, vulnerability assessment, and ethical hacking. Academic and practical work involves identifying and documenting security flaws across authentication, authorization, and input handling layers, following OWASP methodology in controlled lab environments.

Every lab, every finding, and every script produced here is treated as a professional deliverable and documented accordingly.

<br>

## Areas of Focus

| Area | Description |
|---|---|
| **Web Application Pentesting** | Security assessments targeting authentication bypass, authorization flaws, and input validation vulnerabilities. |
| **OWASP Top 10 Analysis** | Hands-on lab work covering injection, broken access control, security misconfigurations, and related vulnerability categories. |
| **Vulnerability Reporting** | Structured findings with impact analysis and remediation guidance written to professional report standards. |
| **Security Automation** | Python and Bash scripting for reconnaissance, enumeration, and workflow automation in security assessments. |
